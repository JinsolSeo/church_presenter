# Church Presenter Phase 2 사용자 안내

## 안전한 시작

앱은 언제나 두 Live 채널을 BLACK으로 시작하며 프로그램 실행 직후 전체화면을
열지 않습니다. 먼저 `화면 / Simulation 설정`에서 Controller, Broadcast,
Venue 역할을 지정하십시오. 물리 화면이 부족하면 Simulation Mode를 선택합니다.
설정을 확인한 뒤에만 `출력 시작`을 누릅니다.

Preview는 다음 콘텐츠를 준비하는 영역이고 Live는 현재 실제 출력입니다. 카드나
페이지 선택은 Preview만 바꾸며, 노란 TAKE 또는 빨간 TAKE BOTH를 눌러야 Live가
변경됩니다. TAKE BOTH는 두 Preview가 모두 준비됐을 때만 함께 적용됩니다.

## 자막과 PDF 동시 진행

Controller 중앙의 `자막 + PDF 동시 진행` 영역에 포커스를 두면 두 Preview에 현재
올라간 콘텐츠 종류를 기준으로 다음 키를 함께 처리합니다. Broadcast Preview가
자막이고 Venue Preview가 PDF라면 각각 다음 자막과 다음 PDF를 준비합니다. 한쪽에만
자막 또는 PDF가 있다면 해당 Preview만 이동합니다.

`함께 이전`, `함께 다음`, `TAKE BOTH · 자막 + PDF` 버튼을 누르면 동시 진행
모드가 꺼져 있어도 자동으로 켜진 뒤 동작합니다. 이동 후 상태줄에는 현재 자막
카드와 PDF 순서 위치가 표시됩니다.

```text
Left / Right   자막 카드와 PDF 페이지를 함께 이전/다음으로 이동
Home / End     자막과 PDF를 각각 처음/마지막으로 이동
Enter          Broadcast 자막과 Venue PDF를 TAKE BOTH
```

중앙 체크박스와 버튼 중 하나를 클릭하면 동시 진행 영역에 포커스가 생기며 굵은
테두리로 표시됩니다. 체크박스는 켜짐/꺼짐 문구와 고대비 색상으로 상태를 표시합니다.
동시 진행이 켜져 있더라도 자막 탭이나 PDF 탭을 클릭해 포커스를 옮기면 방향키와
Enter는 해당 탭에만 적용됩니다.

PDF 고해상도 Preview가 아직 준비되지 않았으면 Enter를 눌러도 기존 양쪽 Live가
유지됩니다. 텍스트 입력 필드에 포커스가 있을 때는 방향키를 가로채지 않습니다.

## 자막

`TXT 열기`로 UTF-8 또는 UTF-8-SIG 파일을 엽니다. 한 개의 비어 있지 않은 원본
줄이 한 자막이며 빈 줄은 읽을 때 제외됩니다. `그룹 n`은 원본을 바꾸지 않고
연속 n줄로 출력 카드를 다시 계산합니다. 왼쪽에서 카드를 고르고 오른쪽에서 그
카드의 원본 줄을 선택해 편집합니다. 추가, 삭제, 위/아래 이동은 메모리에서만
수행되며 `저장` 전에는 원본 파일이 바뀌지 않습니다. 저장은 UTF-8(BOM 없음),
LF 줄바꿈, 빈 줄 제외 정책입니다.

자막 탭에서 Left/Right, Home/End로 Preview를 이동하고 Enter로 Broadcast TAKE를
실행합니다. 텍스트 입력 중에는 이 단축키가 전환에 사용되지 않습니다.

`Subtitle Style Settings`는 모든 스타일 항목과 세 기본 프리셋을 제공합니다.
대화상자의 Preview 적용은 대화상자 내부 미리보기만 바꾸며, 확인 후 현재
Broadcast Preview에만 적용됩니다. 기존 Live 스타일은 다음 TAKE까지 유지됩니다.

## PDF

`PDF 폴더`로 라이브러리를 지정합니다. 파일명/수정 날짜와 오름/내림차순을
선택할 수 있고, PDF 파일을 패널에 끌어 놓을 수도 있습니다. 폴더 검색, 문서
검증, 페이지 렌더링은 백그라운드에서 처리됩니다. 손상된 PDF에는 경고가
표시됩니다.

페이지 썸네일을 드래그하면 출력 순서를 바꿀 수 있습니다. 이 순서는 원본 PDF를
수정하지 않는 파생 데이터이며 PDF 파일별로 설정에 저장되어 다음 실행에도
복원됩니다. 썸네일 숫자는 원본 PDF 페이지 번호이고, Preview 라벨의 `순서`는
재배치된 진행 위치입니다. Left/Right 및 함께 이동 버튼은 이 순서를 따릅니다.

대상 채널을 Broadcast Preview 또는 Venue Preview로 정하고 썸네일이나 페이지
번호로 선택합니다. 상태가 `준비 완료`가 된 뒤 TAKE 하십시오. PDF는 자르지 않고
원본 종횡비를 유지하며 남는 영역을 검게 표시합니다. Send to Both 후 TAKE BOTH로
양쪽을 함께 전환할 수 있습니다.

여러 페이지 동안 같은 PDF를 Broadcast와 Venue 양쪽에 계속 보낼 때는
`Broadcast + Venue 계속 연동`을 켭니다. 이후 페이지를 선택할 때마다 두 Preview가
자동으로 함께 준비되며 Enter 또는 TAKE BOTH로 송출합니다. 이 모드와 `자막 + PDF
동시 진행`은 목적이 다르므로 한쪽을 켜면 다른 쪽은 자동으로 꺼집니다.

## 화면 분리와 종료

Live 중 물리 화면이 분리되면 해당 채널은 BLACK으로 바뀌고 경고가 표시되며 앱은
계속 실행됩니다. 재연결 후 화면을 다시 지정하고 수동으로 출력하십시오. 종료 시
미저장 자막을 확인하고 두 출력 모두 BLACK으로 칠한 후 출력 창을 닫고 설정을
저장합니다.

## 영상

`영상` 탭에서 폴더, 파일명/수정 날짜 정렬, 오름/내림차순을 지정합니다. 목록
검색은 백그라운드에서 실행됩니다. 파일을 클릭하면 선택 채널 Preview가 LOADING을
거쳐 실제 첫 프레임 CUE가 됩니다. 이때 Live와 배경음악은 바뀌지 않습니다.

```text
파일 클릭 → Preview CUE → TAKE → Live CUE → Play
```

Broadcast 또는 Venue를 명확히 선택한 뒤 TAKE 하십시오. TAKE 후에도 첫 프레임에서
멈추며 Play를 눌러야 영상과 영상 오디오가 시작됩니다. Send to Both는 두 Preview를
모두 준비하고 TAKE BOTH는 양쪽 준비가 성공했을 때만 원자적으로 적용합니다.
TAKE BOTH로 같은 영상을 올린 뒤 Play를 누르면 Broadcast와 Venue가 모두 재생됩니다.
Pause, Stop, 처음으로, 탐색도 양쪽에 함께 적용되며 한쪽을 개별 TAKE하면 연동이
자동으로 해제됩니다. 동일 오디오가 겹치지 않도록 양쪽 연동 중에는 Broadcast 영상의
오디오만 시스템 기본 출력 장치로 재생됩니다.
같은 영상을 다시 선택해도 0초의 첫 프레임으로 새로 Cue됩니다. PDF나 BLACK을
Preview로 선택하면 이전 영상의 TAKE 준비 상태는 자동으로 해제됩니다.

Play/Pause, Stop, 처음으로, 탐색, 볼륨, 음소거를 사용할 수 있습니다. Stop과 자연
종료 및 치명적 재생 오류는 해당 Live만 BLACK으로 전환합니다. Fade는 영상 탭에서
0–2000ms로 설정하며 BLACK/PDF/VIDEO 간 전환에 적용됩니다. 영상이 해당 채널의
Live가 아닐 때는 영상 재생 제어가 비활성화되어 다른 Live를 잘못 BLACK으로 바꾸지
않습니다.

영상 탭에 포커스가 있고 입력 위젯을 편집하지 않을 때 Enter는 선택 채널 TAKE,
Space는 Play/Pause, S는 Stop, Home은 처음으로 이동입니다. 영상 목록의 Left/Right는
파일 선택을 이동합니다. 탐색 슬라이더에 포커스가 있으면 키를 가로채지 않습니다.

## 배경음악

`배경음악` 탭에서 폴더를 지정하고 라이브러리 곡을 더블클릭하거나 복수 선택 후
추가합니다. 오른쪽 재생목록은 드래그로 재배치할 수 있습니다. 선택 곡 재생,
Play/Pause/Stop, 이전/다음, 탐색, 볼륨, 음소거와 반복 없음/한 곡/전체 반복을
지원합니다. 3초 이상 재생한 뒤 이전 곡을 누르면 현재 곡의 처음으로 돌아갑니다.

JSON 재생목록은 저장, 다른 이름으로 저장, 불러오기를 지원하고 마지막 파일이 다음
실행에 복원됩니다. 삭제된 곡은 경고 상태로 남으며 전체 앱을 종료하지 않습니다.
실행을 다시 시작해도 영상이나 음악을 자동 재생하지 않습니다.

실제 영상 Play가 시작되는 순간에만 재생 중인 배경음악이 자동 Pause됩니다. 영상
Preview, TAKE, Pause, Stop, 종료는 음악을 자동으로 변경하거나 재개하지 않습니다.
음악 탭의 Space는 Play/Pause, macOS Command+Left/Right 또는 Windows
Ctrl+Left/Right는 이전/다음 곡입니다.
